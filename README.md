## Featured Projects

### [Discords](https://github.com/havanchau/discords)

A full-stack Discord-style communication platform built as a TypeScript monorepo.

Highlights include:

- Realtime server, channel, direct-message, and notification experiences
- Role-based permissions across servers, channels, messages, invites, voice, and uploads
- Message replies, reactions, editing, soft deletion, pins, unread counts, and typing indicators
- File, image, video, and voice-message uploads with local and Cloudinary storage
- WebRTC foundations for voice, video, and screen sharing
- JWT authentication, DTO validation, guarded routes, rate limiting, Helmet, CORS, and upload allowlists
- Optional browser-side channel passphrase encryption for message text

**Core technologies:** React, Vite, TypeScript, NestJS, Prisma, PostgreSQL, Socket.IO, Redis, WebRTC, Cloudinary, Docker, and npm workspaces.

### [NestOps](https://github.com/havanchau/NestOps)

A self-hosted deployment platform inspired by Railway, Render, and Vercel.

The project explores:

- Project and environment management
- Deployment workflows and operational tooling
- A NestJS API with a React dashboard
- Shared configuration and validation packages
- PostgreSQL persistence with Prisma
- Background processing with BullMQ
- Realtime capabilities with Socket.IO
- Health checks, security middleware, and developer-focused quality gates

**Core technologies:** TypeScript, React, Vite, NestJS, Prisma, PostgreSQL, BullMQ, Socket.IO, Docker, and npm workspaces.
